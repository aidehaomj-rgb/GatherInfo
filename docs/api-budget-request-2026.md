# 关于申请全球贸易情报采集系统外部搜索 API 服务经费的说明

为保障全球贸易情报采集系统持续稳定运行，提升对境内外贸易政策、关税措施、技术性贸易措施、海关监管公告等公开信息的发现能力，拟对系统涉及的外部搜索 API 服务进行年度经费测算和申请。现将有关情况说明如下。

## 一、项目背景

当前系统已接入商务部、USTR、WTO、WCO、World Bank Open Data 等公开网页、RSS 或开放数据源，并配置 Tavily、百度千帆搜索、Search1API、NewsAPI、Bing、UN Comtrade 等可选 API 信息源。上述 API 主要用于补充传统网页/RSS 难以及时覆盖的信息，尤其适用于跨站点检索、关键词监测、国外政策动态补充采集和重点专题分析。

按照当前试运行安排，外部搜索 API 预计调用频率约为每日 5 次，全年约 1,825 次。该用量属于低频验证和日常补充采集规模。

## 二、测算依据

本次测算按每日 5 次调用、全年 365 天计算：

- 日调用量：5 次/日
- 月均调用量：约 150 次/月
- 年调用量：约 1,825 次/年

价格以各平台公开价格页为测算依据，未含税费、汇率波动、支付手续费及平台后续价格调整因素，最终以平台控制台实际结算为准。

## 四、经费建议

结合当前每日约 5 次调用的实际需求，Tavily 和百度搜索的免费额度基本可以覆盖日常试运行，不建议一开始采购高价新闻或商业数据 API。建议采用“免费额度为主、少量备用额度为辅”的方式，先保障系统低成本运行。

建议申请年度经费控制额度：人民币 3,000 元以内。

经费用途建议如下：

- Tavily Search API 备用额度：约 50 美元，折合人民币约 360 元，用于免费额度不足或临时专题加密采集。
- Search1API 年度 Basic 备选服务：约 190 美元/年，折合人民币约 1,370 元，用于作为 Tavily 的备用搜索和网页抓取渠道。
- 百度千帆搜索备用后付费额度：建议预留人民币 200 元，实际低频调用预计不发生费用。
- 汇率、税费、支付手续费和临时增量采集预留：约人民币 1,000 元。

以上合计约人民币 2,930 元，建议按人民币 3,000 元申请年度控制额度。实际执行中可根据采购制度和平台支持情况，优先使用免费额度，确需付费时再按审批流程启用。

## 五、暂不建议采购事项

NewsAPI 商用套餐起步较高，且主要提供新闻摘要和元数据，不提供完整全文，当前阶段投入产出比不高，暂不建议采购。

Bing Search 当前公开计费价格相对较高，且微软旧版 Bing Search API 体系变化较大，建议暂不作为首选。

UN Comtrade Premium 主要适用于大批量贸易统计数据下载和机构级数据分析，当前系统以公开政策信息采集为主，暂不建议采购高级订阅。

RSS.app Pro 年费较高，只有在大量网页需要稳定生成 RSS 且现有 scraper 无法覆盖时再考虑。

## 六、风险控制

一是严格控制调用频率。系统按每日约 5 次进行常规调用，避免无计划批量调用造成费用增加。

二是优先使用免费公开信息源。商务部、USTR、WTO、WCO、World Bank Open Data 等公开网页、RSS 和开放数据源继续作为基础数据来源。

三是设置费用上限。对 Tavily、百度千帆等服务启用控制台限额或余额提醒，防止超预算使用。

四是按季度复盘使用情况。根据调用量、采集效果和信息质量，决定是否继续保留 Search1API 等备用服务。

## 七、结论

按当前每日约 5 次调用量测算，系统日常运行主要依靠免费额度即可满足需求。为保障重点时期、专项任务和接口波动情况下的连续采集能力，建议申请人民币 3,000 元以内的年度外部搜索 API 服务经费控制额度，实行按需启用、据实结算。
