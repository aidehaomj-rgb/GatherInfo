# yz 分支更新说明（2026-08-08）

## 更新概览

本次提交集中整理了全球贸易风险情报系统的前端工作台体验、供应链穿透展示，以及近期海关热点采集的内容质量与证据边界。

## 主要变更

### 1. 全局工作台与交互

- 顶部工作栏显示当前功能、数据链路状态和当日采集量。
- 左侧模块导航支持无可见滚动条滚轮滚动，折叠按钮移至侧栏右上角，折叠后自动避让 Logo。
- 页面切换、侧栏扫描、状态脉冲等动效统一，并支持低动态偏好降级。
- 补充键盘聚焦、按钮语义、响应式布局和长文本自然换行，减少信息被截断的情况。

### 2. 系统配置：界面与显示

- 新增全局字体大小控制，支持 90%—120% 调整。
- 新增内容密度：紧凑、舒适、宽松。
- 新增“减少动态效果”和“增强文字对比度”。
- 支持实时预览、一键恢复默认；偏好保存在当前设备，刷新后自动恢复。
- 界面偏好与后端业务配置解耦，不会随业务配置导入导出传播。

### 3. 供应链穿透

- 统一深色情报工作台视觉，修正完整度、证据和图谱区域的主题混用。
- 新增链路状态栏、节点/关系统计、节点聚焦阅读和动态效果暂停。
- 新增“穿透链路清单”，完整展示所有关联主体和项目，不再只展示前三项。
- 长名称、关系说明和核验缺口允许完整换行；图谱按节点数量自动扩展高度，降低重叠风险。
- 对供应链实体类型增加中文语义映射，提升阅读效率。
- 修复调查级开源证据在 `case_id` 为空时的调查范围查询边界。

### 4. 海关热点采集与质量审查

- 将质量审查从泛化的涉华关联，收紧为可落到中国海关监管环节的传导链。
- 增加中国海关阶段、传导证据、可执行核查等评分字段与准入阈值。
- 明确拒绝仅涉及外国海关征税、外国贸易救济或外国进口商合规的内容。
- 调整热点检索任务、调度配置和预览输出，要求保留可核查的数据表、单证、路线、异常指标及处置动作。
- 补充相关单元测试与采集辅助脚本。
